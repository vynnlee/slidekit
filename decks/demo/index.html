slidekit in five minutes

Slides are one HTML file. This deck shows what that gives you.

Welcome. This deck is also a test bed: open it in the editor and try things while you read the notes. The cover has no animation on purpose. Press the right arrow to move on.

Write

Chapter one is about the file format. Keep it short.

A deck is a folder with one HTML file

Each slide is a section element.

Each step is one attribute.

Speaker notes sit in an aside.

Press the right arrow to reveal the lines one by one. Each click shows one new fact. In the editor, open the Animation tab below the canvas to see the same three lines as bars on a timeline.

Everything fits in a few lines

<section data-slide="content">
  <h2>A title</h2>
  <p data-step="2">Appears on click one</p>
</section>
This is the whole idea. The editor reads and writes exactly this markup, so you can switch between the file and the canvas at any time.

Animate

Chapter two shows the animation model: steps, clicks, and the timeline.
