slidekit

HTML로 만드는 슬라이드 도구

**slidekit**을 소개하는 발표이다. 이 덱 자체가 slidekit으로 만들어졌다. 각 장은 시작하기, 발표, 만들기, AI와 내보내기 순서로 진행한다.

시작하기

첫 장은 앱을 여는 방법과 편집기 구성이다. - 실행 - 새 덱 - 편집기

실행과 새 덱과 편집기

  • bun run slidekit으로 앱이 127.0.0.1:3200에서 열린다.
  • 덱 목록에서 덱을 고르거나 bun run slidekit new <이름>으로 새 덱을 만든다.
  • 편집기는 레이어, 캔버스, 속성 패널, 순서 변경과 복제와 삭제, 노트 입력을 한 화면에서 한다.
  • 더블클릭하면 글자를 고친다. 입력이 1.5초 멈추면 자동 저장하고 Cmd+S로도 저장한다.
앱 실행 한 줄이면 덱 목록이 열린다. **편집은 한 화면**에서 끝나고, 저장은 자동이다.

발표

두 번째 장은 발표 중 사용하는 조작이다. 이동 규칙과 발표자 화면을 다룬다.

이동과 발표자 화면

  • 슬라이드 이동은 방향키만 한다. 클릭, 스페이스, 스와이프로는 넘어가지 않는다.
  • F는 전체화면, O는 전체 보기, B와 W는 화면을 검게 또는 희게 가린다. 숫자를 입력하고 Enter를 누르면 그 번호의 장으로 간다.
  • 발표자 화면은 현재와 다음 슬라이드, 노트, 타이머와 시계, 장 위치를 보여 주고 항목마다 켜고 끌 수 있다.
  • 외장 모니터가 있으면 발표 화면을 그 모니터에 전체화면으로 띄운다(Chrome 계열).
이동 수단을 방향키로 제한한 이유는 **발표 중 오작동을 막기 위해서**이다. 발표자 화면의 항목은 필요한 것만 켜 둔다.

만들기

세 번째 장은 덱을 쓰는 규격이다. 종류, 토큰, 노트, 글꼴, 단계 등장을 다룬다.

규격과 토큰과 노트와 글꼴

  • 슬라이드 종류는 cover, chapter, content, end 네 가지이고 장 표지에는 data-title이 필요하다.
  • 화면은 1920x1080 고정이고 창에 맞춰 엔진이 줄이고 늘린다.
  • 색, 글꼴, 여백, 글자 크기는 --sk- 토큰이고 편집기의 토큰 패널에서 바꾼다.
  • 노트는 <aside data-notes>에 마크다운으로 쓴다. 글꼴은 번들 때 쓰는 글자만 남겨 인라인한다.
덱은 **네 종류의 슬라이드**와 토큰으로 구성된다. 글꼴은 Google Fonts, CDN 글꼴 CSS, 폴더 안 글꼴 파일 어느 것이든 같은 방식으로 처리된다.

방향키로 하나씩 나타난다

이 슬라이드는 data-step을 실제로 사용한다.

  • data-step="N"을 달면 N단계부터 보인다.
  • 효과는 data-step-effect로 rise, fade, none 중 고른다.
  • JS가 필요 없다.
방향키를 누를 때마다 항목이 하나씩 나타난다. 두 번째는 **fade**, 세 번째는 **none** 효과이다.

AI와 내보내기

마지막 장은 AI 연동과 산출물이다. 코멘트 흐름, 번들, PDF, 배포를 다룬다.

AI와 함께

  • 편집기에서 요소를 골라 코멘트를 남기면 열려 있는 Claude Code 세션이 받아 덱을 고치고 답한다(Claude Code Channels).
  • 코멘트는 파일에도 저장된다.
  • 저장소의 .claude/skills/slidekit 스킬을 읽은 AI는 규격에 맞는 덱을 새로 만들 수 있다.
  • slidekit lint가 위반을 알려 준다.
수정 요청은 **요소 단위 코멘트**로 전달한다. 스킬과 lint가 있어서 AI가 만든 덱도 규격을 지킨다.

내보내기

  • slidekit bundle은 엔진, 이미지, 글꼴을 담은 HTML 파일 하나를 만든다.
  • slidekit pdf는 슬라이드당 한 페이지, 16:9 PDF를 만든다.
  • slidekit deploy는 static.vynnlee.com에 올리고 공개 또는 비밀번호를 고른다.
  • 편집기의 Export 메뉴에서도 같은 일을 한다.
산출물은 **번들, PDF, 배포** 세 가지이다. 명령과 Export 메뉴는 같은 기능을 쓴다.
