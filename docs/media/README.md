# Media for the README and docs

Screenshots and recordings used by `README.md`, `README.ko.md` and the docs live here.

## Naming and format

- Lowercase words joined by `-`, no spaces: `editor.png`, `present.gif`, `comments-panel.png`, `agent-presence.gif`.
- Screenshots: PNG, 1440 px wide (retina captures downscaled), dark theme, a sample deck with no private content. Keep each under about 400 KB (optimize with `pngquant` or similar).
- Animations: GIF or MP4/WebM, 15 seconds or less, under 3 MB for GIF. Prefer a short MP4 or WebM for anything longer.
- Reference them with relative paths, for example `![Editor](docs/media/editor.png)`.
- Only use decks and comments that are fine to publish. Never capture your real decks, private comments, tokens, or your home directory path.
